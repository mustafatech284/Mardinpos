# Mardin POS — v1 starter

ئەمە سەرەتای پرۆژەی Android ـە بۆ Mardin POS.

لە وەشانی داهاتوودا پێویستە زیاد بکرێن:
- SQLite/Room بۆ هەڵگرتنی ناوخۆیی
- Cloud sync و login بۆ چەند ئامێر
- بەڕێوەبردنی مارکێت و قەرز
- بارکۆد سکەنکردن
- ڕاپۆرتی قازانج
- چاپکردنی پسوڵە
- Backup و security

بۆ بیلدکردن، پرۆژەکە لە Android Studio بکەرەوە و Gradle Sync/Build بکە.
